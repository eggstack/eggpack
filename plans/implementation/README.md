# Milestone Implementation Plans

Implementation plans are bounded operational handoffs tied to a concrete repository baseline.

Path:

```text
implementation/<subsystem>/NNN-short-title.md
```

Each plan MUST include:

1. objective;
2. readiness/dependencies;
3. current evidence;
4. invariants;
5. in/out scope;
6. required production changes;
7. ordered work packages;
8. failure/restart/contention semantics;
9. compatibility/migration;
10. required tests;
11. verification commands;
12. documentation updates;
13. acceptance criteria;
14. stop conditions;
15. closure evidence;
16. handoff notes.

Cross-repository plans MUST record the external source baseline. Corrective work receives a new plan; prior plans/closure history remain intact.
